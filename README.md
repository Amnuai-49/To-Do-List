# To-Do List

โปรแกรมจัดการรายการงานบนเทอร์มินัล เขียนด้วย Python และบันทึกข้อมูลลงใน
`tasks.json` พร้อมระบบแจ้งเตือนตามวันที่และเวลา

## ความต้องการของระบบ

- Python 3.9 ขึ้นไป
- ใช้เขตเวลา `Asia/Bangkok` สำหรับระบบแจ้งเตือน

## วิธีใช้งาน

รันโปรแกรมจากโฟลเดอร์โปรเจกต์:

```bash
python main.py
```

เมนูหลัก:

1. เพิ่มงาน โดยระบุชื่อ รายละเอียด วันที่ และเวลา
2. แสดงงานทั้งหมด
3. ทำเครื่องหมายงานว่าเสร็จแล้ว
4. แก้ไขงาน โดยเว้นช่องวันที่หรือเวลาเพื่อใช้ค่าเดิม
5. ลบงาน
6. ค้นหาจากชื่อหรือรายละเอียดงาน
7. ออกจากโปรแกรม

วันที่ต้องใช้รูปแบบ `YYYY-MM-DD` และเวลาต้องใช้รูปแบบ `HH:MM`

## ระบบแจ้งเตือน

โปรแกรมตรวจสอบงานที่ยังไม่เสร็จทุก 1 วินาทีในเธรดเบื้องหลัง เมื่อถึงเวลาที่กำหนด
จะแสดงการแจ้งเตือนในเทอร์มินัลและบันทึกสถานะ `reminded` เพื่อไม่ให้เตือนซ้ำ

## รูปแบบข้อมูล

แต่ละงานใน `tasks.json` มีโครงสร้างดังนี้:

```json
{
	"title": "อ่านหนังสือ",
	"des": "บทที่ 1",
	"date": "2026-09-30",
	"time": "18:30",
	"complete": false,
	"reminded": false
}
```

หากไฟล์ไม่มีอยู่, JSON ไม่ถูกต้อง หรือข้อมูลไม่ใช่รายการ โปรแกรมจะเริ่มด้วยรายการงานว่าง

## การทดสอบ

รันเทสต์ด้วย Python standard library โดยไม่ต้องติดตั้ง `pytest`:

```bash
python -m unittest -v test_notification.py
```

ตรวจ syntax ของไฟล์ Python:

```bash
python -m py_compile main.py test_notification.py
```

## สร้างเอกสาร PDF

`generate_summary_pdf.py` ต้องใช้แพ็กเกจ `reportlab` และฟอนต์ภาษาไทยที่อยู่ใน `.fonts`:

```bash
pip install reportlab
python generate_summary_pdf.py
```

ไฟล์ PDF จะถูกสร้างเป็น `main_summary_th.pdf`
